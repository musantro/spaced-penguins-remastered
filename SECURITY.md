# Security policy

## Scope

The production site is a static browser build. It does not provide an account
system, backend API or global score submission service, and the local score
form intentionally keeps the nickname in the browser.

## Reporting a problem

Please do not publish secrets, private reference files or an exploitable issue
in a public issue. Use GitHub's private vulnerability reporting flow for this
repository when available; otherwise contact the maintainer through the
repository owner's GitHub profile and include reproduction steps, affected
versions and impact.

Issues involving third-party historical software or assets should also be
reported to their respective rights holder or vendor where appropriate.
